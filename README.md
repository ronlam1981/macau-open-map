# 澳門開放地圖

Leaflet + OpenStreetMap，GitHub Pages 靜態網站。

40 個已接入圖層、4,676 個地點，完整目錄 1,376 個數據集。原有政府資料為 2026-09-20 取得的快照；巴士資料於 2026-10-13 取得；API 標記代表來源提供 API，不代表即時更新。未設置自動更新排程。

來源：澳門特別行政區政府數據開放平台 https://data.gov.mo/Datasets 。地圖 © OpenStreetMap contributors。

index.html 是可直接部署的獨立網頁。非政府官方作品。停車場只有位置資訊，未接即時剩餘車位。定位只在瀏覽器處理。

## 篩選方式

依序選擇「設施分類 → 細分資料圖層 → 名稱或地址」。三者共同篩選；改分類會重設圖層並保留關鍵字。清除篩選回到全部地點。我的附近按目前結果的直線距離排序，再按一次可取消。

2026-10-12 更新篩選邏輯及無障礙公廁分類；政府資料取得日期仍是原有快照日期。

修改 `template.html`、`app.js` 或 `app.css` 後，執行 `python scripts/build.py` 和 `python scripts/validate.py`。建置會更新根目錄 `index.html`；未有獨立資料檔時使用現有首頁內的資料快照。

## 巴士站及路線（2026-10-13 接入）

「交通出行 → 巴士站及巴士路線」包含官方 2026-09-29 更新資料包的 613 個站點、101 個路線編號及 123 組方向／行程。可搜尋站名、站號和路線編號，選擇方向查看官方路線走向及站序。此資料為靜態快照，臨時改道與即時到站資訊請查交通事務局巴士報站。

座標：官方 Macau Grid WKT 的投影參數及 International 1924 橢球經核對後，以 EPSG:8433 → EPSG:4326 轉換，採用 PROJ 非近似大地基準轉換（標示精度 1 米）。

重新取得巴士資料：安裝 `pyshp pyproj pandas xlrd`，先準備 `data/site-data.json`（可從首頁 dataset 抽出），執行 `python scripts/import_bus.py`，再建置及驗證。匯入程式會校驗所有站序與路段參照及澳門座標範圍。
